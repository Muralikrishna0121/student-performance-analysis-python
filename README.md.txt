# Student Performance Analysis Using Python

## Project Overview
This project analyzes student performance data to identify academic trends, subject averages, top-performing students, and factors influencing exam scores.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Data Collection
2. Data Validation
3. Exploratory Data Analysis
4. Performance Visualization
5. Insights Generation

## Key Analysis
- Subject-wise Average Scores
- Top 5 Students Identification
- Gender-wise Performance Analysis
- Parental Education Impact
- Race/Ethnicity Performance Analysis

## Visualizations
- Math Score Distribution
- Average Scores by Gender
- Parental Education vs Performance
- Race/Ethnicity vs Scores
- Reading Score Distribution
- Writing Score Distribution
